* **Importa ValenCommons desde mi [listado público de VCC](https://valenvrc.com/)⚠️**
* Importa RoomSystem.unitypackage
* Localiza el prefab RoomSystem dentro de `Packages/Valenvrc - RoomSystem/Runtime/` y arrástralo a tu escena.
* Sigue las instrucciones de esta wiki para personalizarlo a tu gusto.

## Configurar una Sala

El prefab predeterminado de RoomSystem viene con una sala de muestra ya configurada, puedes usarla como referencia para crear tus propias salas. Para crear una nueva sala:

1. Duplica la plantilla `Room1` que se encuentra dentro del GameObject `Rooms`.
![alt text](/img/docs/room-system/room-duplicate.png)
2. Agrega la nueva sala al array `Rooms` en el componente `RoomSystem`.
3. Redimensiona el collider de la sala para que se ajuste a toda el área de tu sala.
![alt text](/img/docs/room-system/room-collider.png)
