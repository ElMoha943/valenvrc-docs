- Encuentra el prefab en `Packages/valenvrc - BouncerSystem/Runtime` y arrástralo a tu escena.
- Agrega los nombres de usuario de tu personal de seguridad en la lista "SecurityNames".
- Opcionalmente cambia las listas de objetos activados/desactivados para usuarios de seguridad y verificados.

### Settings

- DebugMode : bool - Habilita mensajes de log adicionales en la consola.
- UdonConsole : UdonConsole - Referencia opcional a la consola UdonLogger de Varneon.
- RespawnOnUnverify : bool - Si los jugadores deben ser regenerados cuando no están verificados.
- IOIsSecurity : bool - Si es true, otorga automáticamente estado de seguridad al creador de la instancia.
- SecurityNamesUrl : VRCUrl - URL externa para obtener nombres de usuario de seguridad.
- SecurityRole : KeyPadRol - Si el jugador tiene este KeyPadRol será automáticamente conectado como seguridad.
- SecurityNames : string[] - Lista de nombres de usuario que serán automáticamente conectados como seguridad.
- SecurityObjectsOn : GameObject[] - Lista de objetos que se activarán para usuarios de seguridad.
- SecurityObjectsOff : GameObject[] - Lista de objetos que se desactivarán para usuarios de seguridad.
- VerifiedRole : KeyPadRol - Si el jugador tiene este rol será automáticamente verificado.
- VerifiedObjectsOn : GameObject[] - Lista de objetos que se activarán para usuarios verificados.
- VerifiedObjectsOff : GameObject[] - Lista de objetos que se desactivarán para usuarios verificados.

### References

No deberías necesitar cambiar estos a menos que sepas lo que estás haciendo.

BUD : BouncerUserData - PlayerObject que almacena el nivel de seguridad de cada jugador.
LoadingScreen : GameObject - Se activará mientras la lista de usuarios en la gui se está actualizando.
