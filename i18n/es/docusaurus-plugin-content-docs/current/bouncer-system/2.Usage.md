El sistema está diseñado para restringir el acceso a características específicas de tu mundo a nuevos usuarios (invitados) antes de ser verificados manualmente por un usuario de **Seguridad**. Hay múltiples formas de seleccionar tus usuarios de seguridad detalladas en [Instalación](./install).

### Verificar otro jugador

Una vez que eres un usuario de Seguridad, puedes usar la GUI para encontrar el nombre de usuario del jugador que deseas verificar y hacer clic en el Toggle junto a su nombre en la columna "Verified". Verás que cambia a una marca de verificación si tiene éxito. De la misma manera, puedes hacer clic en el toggle nuevamente para desverificarlos.

![Bouncer System UI](image.png)

También puedes usar el prefab **Scanner** y arrastrarlo a tu jugador objetivo, luego usarlo (presionar gatillo en VR o Clic Izquierdo en Escritorio) y verás que cambia de color. El color verde significa verificado exitosamente, rojo significa que estás muy lejos o ocurrió algún otro error. **No puedes usar el scanner para desverificar usuarios**.

:::tip
Puedes ajustar la distancia máxima del scanner en el script adjunto a él.
:::

### Otorgar estado de seguridad a otro jugador

También puedes usar la GUI para otorgar **Acceso de Seguridad Temporal** a usuarios en la instancia, este estado solo dura hasta que abandonen la instancia. Cualquier seguridad permanente puede agregar/eliminar acceso de seguridad temporal pero no puedes eliminarlo de aquellos que están en listas permanentes.
