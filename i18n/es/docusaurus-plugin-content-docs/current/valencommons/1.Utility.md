### Invoke

Usado para enviar UdonEvents cuando un jugador interactúa con un objeto.

- Target-MethodPairs - Lista de UdonBehaviours junto con el nombre del evento que será activado.

![Invoke Script Example](/img/docs/valencommons/invoke-script-example.png)

### TriggerInvoke

Usado para enviar UdonEvents cuando un jugador entra a un trigger.

- Target-MethodPairs - Lista de UdonBehaviours junto con el nombre del evento que será activado.

### OpenGroupButton

Usado para abrir una página de grupo específica cuando un jugador interactúa con un objeto.

- GroupIdentifier : string - identificador del grupo que quieres abrir.

:::note
Para obtener el identificador del grupo ve a tu grupo y copia la última parte de la url que comienza con `grp_`.
:::

:::tip
Puedes llamar a `_OpenGroupPage` para llamarlo desde un botón UI.
:::

### GestureInvoke

Un script de utilidad usado para realizar diferentes acciones cuando un jugador hace un cierto *gesto*.

- Require Trigger Pressed : bool - Si el gesto requiere que el botón de gatillo del joystick esté presionado.
- Gesture Type:
  - KeyPress - Se activa al presionar una tecla específica del teclado.
  - Right/Left Joystick up/down seconds - Se activa al mantener el stick durante x cantidad de segundos.
  - Right/Left Joystyick up/down times - Se activa al realizar x cantidad de movimientos consecutivos.
- Times : int - Define ya sea tiempo en segundos o cantidad de movimientos consecutivos requeridos para activar.
- GracePeriod : float - Tiempo aceptable entre movimientos consecutivos.
- Gesture Action:
  - Toggle - Alterna el estado activo de un objeto.
  - TeleportObject - Teletransporta un objeto a la ubicación objetivo.
  - TeleportSelf - Te teletransporta a la ubicación objetivo.
- Target Object : GameObject - El objeto que será teletransportado/alternado.
- Target Position:
  - Front
  - Right Hand
  - Left Hand
  - Custom
- TPpoint : transform - Punto objetivo para la opción de posición objetivo "Custom".
- Progress Slider : slider - Slider opcional para mostrar progreso de la completación del gesto.

![AdminTablet Gesture](/img/docs/valencommons/admintablet-gesture.png)

### Collider Activator

Activa/desactiva un conjunto de Colliders dependiendo del estado activo del GameObject al que está adjunto.

- Colliders : Collider[] - Lista de colliders para habilitar/deshabilitar.
