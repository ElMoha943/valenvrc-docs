Una selección de scripts para controlar parámetros de animadores.

### Animator Toggle

Alterna un parámetro booleano en un componente Animator. Se puede usar **Interactuando** con él si tiene un Collider adjunto o llamando a `_Toggle()` desde un componente UI u otro script.

- Anim : Animator - El componente Animator a controlar.
- ParameterName : string - El nombre del parámetro booleano a alternar.

### Synced Animator Toggle

Igual que **Animator Toggle**, pero sincronizado con todos los jugadores.

- Anim : Animator - El componente Animator a controlar.
- ParameterName : string - El nombre del parámetro booleano a alternar.

### Trigger Animator Toggle

Alterna un parámetro booleano en un componente Animator cuando un jugador entra en un collider trigger. Se puede usar adjuntando un Collider con "Is Trigger" activado.

- Anim : Animator - El componente Animator a controlar.
- ParameterName : string - El nombre del parámetro booleano a alternar.
- WorkForAllPlayers : bool - Si está activado, cualquier jugador que entre en el trigger alternará el parámetro para todos los jugadores. Si es falso, solo se detectará al jugador local.

### Animator Activator

Alterna un parámetro booleano basado en el estado activo del GameObject al que está adjunto.

- Anim : Animator - El componente Animator a controlar.
- ParameterName : string - El nombre del parámetro booleano a alternar.

### Dinstance Animator Trigger

Controla un parámetro flotante de un animador basado en la distancia entre el jugador local y un punto específico.

- MinDistance : float - A esta distancia o más lejos, el parámetro se establecerá en 0.
- MaxDistance : float - A esta distancia o más cerca, el parámetro se establecerá en 1.
- TargetAnimator : Animator - El componente Animator a controlar.
- ParameterName : string - El nombre del parámetro flotante a controlar.
- TargetTransform : Transform - El punto desde el cual medir la distancia.
