Una selección de scripts para alternar varias cosas activadas y desactivadas.

### Trigger Toggle

Alterna el estado activo de un GameObject cuando un jugador entra en un collider trigger. Se puede usar adjuntando un Collider con "Is Trigger" activado.

- ToggleableObjects : GameObject[] - Los GameObjects a alternar.

:::note
Solo funciona para el jugador local.
:::
