- Encuentra el prefab en `Packages/valenvrc - Drinking Roulette/Runtime` y arrástralo a tu escena.
- Redimensiona el **AutoOptInTrigger** encontrado dentro del gameobject OptInOut.
  - Opcionalmente, deshabilita el trigger y usa los botones OptIn y OptOut en su lugar.
- Navega esta wiki para aprender cómo cargar tus paquetes de prompts personalizados e idiomas.

### Settings

- DebugMode : bool - Imprime mensajes adicionales en la consola.
- NoRepeatMode : bool - Si es true, almacena una lista de prompts que ya aparecieron para evitar duplicados. Se reinicia automáticamente si todos los prompts han sido usados.
- Cooldown : float - Tiempo en segundos a esperar entre giros.
- WheelSets : WheelSet[] - Lista de *WheelSets* (paquetes de prompts) disponibles para usar.

### References

No deberías necesitar tocar estos a menos que sepas exactamente lo que estás haciendo.

- FloatingText : TextMeshProUGUI - Texto donde se muestra el prompt actual.
- LastSpunBy : TextMeshProUGUI - Texto para mostrar el nombre de usuario del último jugador que giró la rueda.
- BottleAnimator : Animator - Animator de la botella.

:::note
La botella de la ruleta siempre gira la misma cantidad y aterriza en el mismo lugar, no está destinada a ser usada como selección de jugador, ver [variables](./wheel-sets#variables) para una forma adecuada de seleccionar aleatoriamente un jugador para prompts.
:::
