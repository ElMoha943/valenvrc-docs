La ruleta puede cargar diferentes idiomas localmente para que cada usuario vea los prompts en su propio idioma nativo.
Hay múltiples formas de seleccionar tu idioma:

### Botones de Cambio de Idioma Incluidos

Hay scripts **ChangeLangButton** incluidos que puedes usar para cambiar el idioma a una clave específica al interactuar.

### API

Puedes llamar a `public void _ChangeLanguage(string ll)` donde li es la clave del idioma al que cambiar.

### Verbatim

La ruleta también soporta **[Verbatim](https://vowgan.gumroad.com/l/verbatim)** por vowgan, para habilitar simplemente importa verbatim y activa el gameobject "RouletteVerbatimIntegration".
