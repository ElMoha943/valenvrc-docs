## Security

Esta parte se usa para conectar con sistemas externos para verificaciones de seguridad.

* **PlayerTags**: usa el sistema de [PlayerTags](https://creators.vrchat.com/worlds/udon/players/getting-players/#player-tag-system) integrado en vrchat.
  * **TagName**: nombre de la etiqueta.
  * **SplitChar**: carácter para separar etiquetas.
* **SecurityKeypad**: usa los nombres de roles del [Security Keypad](https://store.valenvrc.com/i/SecurityKeypad) para permisos.
  * Referencia al Security Keypad.
* **UdonBridge**: [En Desarrollo]
* **VRCLinking**: [En Desarrollo]

:::info
La tableta en sí no incluye un sistema de gestión de roles, ¡necesitas otro sistema para que funcione!
:::

## References

Estas son referencias usadas por la tableta, principalmente componentes de UI, no deberías necesitar tocarlas a menos que sepas exactamente lo que estás haciendo.

* Handle - El mango de la tableta, es donde está el componente pickup y es afectado por el redimensionamiento.
* POV Camera - Gameobject FollowerCamera, se colocará en la cabeza del jugador objetivo mientras esté en la pestaña de perfil.
* Profile - Pestaña ModerationView. Pestaña especial que se abre cuando haces clic en el nombre de un jugador en la pestaña de moderación; muestra información del jugador y acciones de moderación.
* HiddenParent - Donde se colocarán las pestañas inactivas.
* Active Parent - Donde se colocará la pestaña activa.
* Content - El contenido del viewport que se llena con botones de jugador dentro de la pestaña de moderación.
* Title_Username - TextMeshProUGUI dentro de la pestaña de perfil que muestra el nombre del jugador objetivo.
* Title_OnlineUsers - TextMeshProUGUI dentro de la pestaña de moderación que muestra la cantidad de jugadores.
* DummyButton - Prefab usado para instanciar los botones de jugadores en la pestaña de moderación.
* EmptyTabPrefab - Prefab usado para instanciar nuevas pestañas desde la configuración.
* SelectorContent - Donde se colocan los botones de pestaña.
* SelectorButtonPrefab - Prefab usado para instanciar los botones de pestaña en el selector.
* ClickSound - Sonido que se reproduce al hacer clic en botones.
* TabChangeSound - Sonido que se reproduce al cambiar de pestaña.
