Los módulos son partes de la tableta que puedes agregar/eliminar para ajustar su funcionalidad.

## Agregar Módulos

Para agregar un módulo, ve al script principal de la tableta, bajo el desplegable "Modules" encontrarás 2 menús desplegables para seleccionar el módulo que deseas agregar y la pestaña a la que deseas agregarlo. También puedes agregar módulos manualmente arrastrándolos desde la carpeta de prefabs o agregándolos como componentes. Puedes eliminar módulos haciendo clic en la X roja junto a ellos o eliminándolos de la jerarquía.

![Modules List](/img/docs/admin-tablet/modules-list.png)

:::tip
La lista de módulos debería actualizarse automáticamente, si no puedes forzar una actualización usando el botón "Get Connected Modules", ¡asegúrate de que todos los módulos de tu tableta estén listados o pueden no funcionar correctamente!
:::

## Ajustar configuración de Módulos

Cada módulo tiene su propia configuración, verás una lista de todos los módulos conectados en el script principal de la tableta, puedes editar cada una de sus configuraciones desde ahí. También puedes editarlas directamente desde sus gameobjects.

![Module Settings](/img/docs/admin-tablet/module-settings.png)
:::tip
Si deseas editar textos de etiquetas, imágenes u otras configuraciones de botones, necesitarás hacerlo directamente en el gameobject del módulo. Puedes acceder a ellos fácilmente haciendo clic en la referencia al módulo en la lista.
:::

## Restringir acceso a módulos

Puedes usar el botón **Edit Permissions** para agregar **Permission Tags** requeridos para usar el módulo. El botón cambiará de amarillo a verde cuando las etiquetas estén configuradas. Para deshabilitar permisos completamente en un módulo simplemente deja las etiquetas vacías. También puedes editar las etiquetas directamente desde los gameobjects de los módulos.

Los Permission Tags actuarán de manera diferente dependiendo de qué sistema de seguridad estés usando, por defecto esto usa el [Sistema de Etiquetas de Jugador de VRChat](https://creators.vrchat.com/worlds/udon/players/getting-players/#player-tag-system) pero puedes usar el menú desplegable bajo la sección "Security" para elegir otros sistemas.

:::warning[NOTA IMPORTANTE]
La tableta de administración no viene con su propio gestor de permisos integrado, necesitarás usar una solución de terceros. Si deseas un sistema de permisos que sea 100% compatible e incluso expanda la funcionalidad de la tableta aún más, revisa el **[SecurityKeypad](https://store.valenvrc.com/SecurityKeypad)**
:::

## Lista de Módulos

### Local TP Module

Teletransporta al usuario local a la posición objetivo.

- Zone : transform - posición donde el usuario será teletransportado.

### Global TP Module

Teletransporta a todos a la posición objetivo.

- Target : transform - posición donde los usuarios serán teletransportados.
- TeleportCaster : bool - si es true, también te teletransporta cuando se presiona.

### Bringall Module

Teletransporta a todos hacia ti.

### Announcement Module

Muestra un mensaje en la pantalla de todos por un par de segundos.

### Synced Toggle Module

Activa/desactiva un conjunto de objetos para todos en la instancia.

- Toggleables : GameObject[] - Lista de objetos que se activarán cuando el estado del toggle sea True.
- Toggleablents GameObject[] - Lista de objetos que se desactivarán cuando el estado del toggle sea True.
- ToggleState : bool - Valor predeterminado del toggle sincronizado.
- TrueText : string - Texto que se mostrará en la notificación cuando el estado del toggle sea True.
- FalseText : string - Texto que se mostrará en la notificación cuando el estado del toggle sea False.
- EnabledColor : Color - Color al que cambiará el botón cuando el estado del toggle sea True.

### ObjectRespawn Module

Regenera una lista de objetos sincronizados.

- RespawnObjects : VRCObjectSync[] - Lista de objetos a regenerar.

### Warn Module

Muestra un mensaje en la pantalla del usuario objetivo.

### Bring/Goto Module

Teletransporta al usuario objetivo hacia ti.
Te teletransporta al usuario objetivo.

### Freeze Module

Hace que el usuario objetivo no pueda moverse.

### Mute/Deafen Module

Hace que el usuario objetivo no pueda hablar/escuchar.

- DefaultVoice : float - El valor predeterminado de VoiceDistanceFar, usado para restablecer la voz de un usuario que fue desmuteado.
- UnmuteOnDisconnect : bool - Si es true, si un usuario abandona la instancia será removido de la lista de muteados.

### Ban Module

Envía al usuario a un punto específico, establece su spawn ahí y (opcionalmente) lo congela.

- Banzone : transform - Ubicación de baneo
- ShouldFreeze : bool - si es true, congela al jugador al banearlo.

### Remote TP Module

Teletransporta al usuario objetivo a la posición objetivo

- Zone : transform - posición donde el usuario será teletransportado.

### Follower Camera

Usado para mostrar la vista del jugador objetivo en la pestaña de perfil.

- FPS : int - tasa de refresco de la cámara, reduce para aumentar el rendimiento.

## Addons

Los addons son módulos que dependen de assets de terceros o que han sido creados por la comunidad. Se proporcionan tal cual y no tienen soporte. Si creaste un módulo personalizado que quieres agregar a los archivos principales, ¡contáctame en discord!

### Access Module

Otorga al usuario objetivo un KeyPadRol del SecurityKeypad

- VipRole : KeyPadRol - El KeyPadRol para otorgar al usuario.
