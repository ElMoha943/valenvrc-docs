El cambiador de temas te permite modificar fácilmente la apariencia general de tu tableta usando 4 colores.
También puedes exportar e importar tu configuración para transferirla fácilmente de proyecto a proyecto o hacer respaldos antes de actualizar.
También puedes establecer la imagen de fondo desde aquí.
