* **Importa ValenCommons desde mi [listado público de VCC](https://valenvrc.com/)⚠️**
* Importa AdminTablet.unitypackage
* Localiza el prefab AdminTablet dentro de `Packages/Valenvrc - AdminTablet/Runtime/AdminTablet` y arrástralo a tu escena.
* Sigue las instrucciones de esta wiki para personalizarlo a tu gusto.

:::danger[Consideraciones Importantes:]

* NUNCA desactives el gameobject de la tableta o sus módulos, todos son necesarios para que la tableta funcione correctamente.
* Mantén todos los módulos como hijos del script principal Tablet o no podrán encontrar la referencia a él para las notificaciones y verificaciones de permisos.

:::
