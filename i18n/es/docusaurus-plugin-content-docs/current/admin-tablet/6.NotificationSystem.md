El sistema de notificaciones se usa para registrar y mostrar acciones al usuario. Es importante dejarlo habilitado para cumplir con las [Pautas de Herramientas de Moderación](https://hello.vrchat.com/creator-guidelines).

### Settings

- ShowNotifications : bool - Muestra notificaciones en pantalla.
- ShowLogs : bool - Imprime logs en la consola.
- Time : Float - Tiempo en segundos que las notificaciones en pantalla permanecen.
- MaxNotifications : int - Cantidad máxima concurrente de notificaciones en pantalla.
- NotificationIcon : Sprite - Icono predeterminado para notificaciones.
- NotificationSound : AudioClip - Sonido predeterminado para notificaciones.
- Volume : Float - Volumen de los sonidos de notificaciones.
- UdonConsole : UdonConsole - Referencia opcional para VUdonLogger Console.

### Notifications

Puedes ajustar algunas cosas en cada tipo de notificación incluyendo:

- Habilitarla/Deshabilitarla completamente
- Icono
- Sonido
- Traducciones, en las cuales el {0} significa variables.

### References

Referencias internas usadas por el sistema, *no deberías necesitar tocarlas*

- Container : transform - donde aparecerán nuevas notificaciones.
- DummyNotification : GameObject - prefab desde el cual se instancian nuevas notificaciones.
