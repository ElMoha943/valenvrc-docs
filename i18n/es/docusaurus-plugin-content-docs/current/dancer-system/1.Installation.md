- Encuentra el prefab en `Packages/valenvrc - DancerSystem/Runtime` y arrástralo a tu escena.
- Agrega los nombres de usuario de manager y dancer en las listas respectivas.
- Opcionalmente ajusta la configuración en los scripts de dancersystem y dancer counter.

## Configuración del Dancer System

- DebugMode : bool - Habilita mensajes de log adicionales en la consola.
- Managers : string[] - Lista de nombres de usuario que tendrán permisos de manager.
- Manager Role : KeyPadRol - Si el jugador tiene este KeyPadRol será automáticamente conectado como manager.
- Dancers : string[] - Lista de nombres de usuario que tendrán permisos de dancer.
- Dancer Role : KeyPadRol - Si el jugador tiene este KeyPadRol será automáticamente conectado como dancer.

### Configuración del Dancer Counter

- ManagersSeeCountersByDefault : bool - Si es verdadero, los managers verán los contadores de dancer cuando se unan a la instancia.
- DancersSeeCountersByDefault : bool - Si es verdadero, los dancers verán los contadores de dancer cuando se unan a la instancia.
- RestrictCountersToDancersAndManagers : bool - Si es verdadero, solo los dancers y managers podrán activar los contadores. Deja desactivado si planeas tener dancers invitados o noches abiertas.

:::tip
Configuraciones adicionales están ubicadas en el prefab [**DanceCounter**](./dance_counters), ubicado en `DancerSystem/Counters/DanceCOunter`. Puedes ajustar cosas como máximo de bailes, cambio de color, desplazamiento vertical, etc.
:::

### Configuración de Dancer Lists

- OnlyDancersCanJoin : bool - Si es verdadero, solo los jugadores en la lista de dancers o con el rol de dancer podrán unirse como dancers. Deja desactivado si planeas tener dancers invitados o noches abiertas.
- RemoveOnExit : bool - Si es verdadero, los jugadores serán removidos de la lista de dancers cuando salgan de la instancia.
- DancerLists : DancerList[] - Lista de componentes DancerList para actualizar.
