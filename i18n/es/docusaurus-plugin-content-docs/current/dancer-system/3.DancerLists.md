Las listas de dancers se utilizan para mostrar una lista sincronizada de artistas para la noche, puedes usarla para llevar un registro del orden de baile, es especialmente útil para eventos de escenario abierto o mapas públicos ya que los usuarios pueden agregarse a sí mismos a la lista haciendo clic en un botón. Los Managers también pueden remover dancers de la lista o agregar nombres manualmente si es necesario.

### Referencias de Dancer List

- ButtonPrefab : GameObject - Prefab utilizado para crear cada botón de dancer en la lista.
- JoinButton : GameObject - Botón que los jugadores pueden hacer clic para unirse como dancers.
- LeaveButton : GameObject - Botón que los jugadores pueden hacer clic para salir de la lista de dancers.
- Content : Transform - Transform padre donde se instanciarán los botones de dancers.
