## Instalación

* Importa ValenCommons desde mi [listado público de VCC](https://valenvrc.com/)⚠️
* Importa SecurityKeypad.unitypackage
* Localiza el prefab SecurityKeypad dentro de `Packages/Valenvrc - SecurityKeypad/Runtime/SecurityKeypad` y arrástralo a tu escena.
* Sigue las instrucciones de esta wiki para personalizarlo a tu gusto.
