La mayoría de los addons se crean para brindar compatibilidad con otros assets o para expandir la funcionalidad del keypad. Son opcionales y no tienen soporte oficial, pero puedes probarlos si quieres.

## VRCLinking

El addon VRCLinking te permite vincular los roles del keypad con [VRCLinking](https://vrclinking.com/) para otorgar automáticamente un rol del keypad a usuarios que tengan un rol específico de Discord.

Para configurarlo, solo habilita el addon y haz coincidir los nombres de rol entre los roles del keypad y los roles de VRCLinking.

:::tip
Asegúrate de usar la propiedad real `rolName` y no el nombre del gameobject.
:::

## Role Board

Esto crea una UI simple donde puedes mostrar los nombres de usuario de quienes han iniciado sesión en roles específicos.

RolGroup:

- Keypad: KeyPad - Referencia al keypad del que se obtienen los roles.
- Roles: KeyPadRol[] - Si el jugador tiene cualquiera de estos roles, se mostrará en esta lista.
- GroupNamesText: TextMeshProUGUI - Componente de texto donde se mostrarán los nombres.
