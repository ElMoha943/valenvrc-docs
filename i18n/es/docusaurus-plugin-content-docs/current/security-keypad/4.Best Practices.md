## Jerarquías de Roles

En el 90% de los casos tu mundo/club/comunidad tiene una jerarquía de roles, por ejemplo:
`Admin -> Staff -> DJ -> VIP -> Usuario Normal`

:::note
No necesitas tener un rol para "Usuario Normal", este es un usuario sin rol.
:::

En estos casos, los roles superiores usualmente tienen todos los permisos de los roles inferiores, ahí es cuando la característica de **Child Role** entra en juego, es una forma fácil de proporcionar a un rol todos los permisos de otro sin tener que cambiarlos manualmente en cada rol, de esa manera tu configuración de roles es limpia y fácil de mantener.

:::tip
Puedes usar la **Keypad Checker Tool** (en la barra superior: valenvrc > keypad > checker tool) para buscar entradas duplicadas y bucles y tener una vista clara de tu jerarquía.
:::
