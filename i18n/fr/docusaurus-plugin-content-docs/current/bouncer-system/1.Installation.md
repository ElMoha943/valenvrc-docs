- Trouvez le prefab dans `Packages/valenvrc - BouncerSystem/Runtime` et glissez-le dans votre scène.
- Ajoutez les noms d'utilisateur de votre personnel de sécurité dans la liste "SecurityNames".
- Changez optionnellement les listes d'objets activés/désactivés pour les utilisateurs de sécurité et vérifiés.

### Settings

- DebugMode : bool - Active les messages de log supplémentaires dans la console.
- UdonConsole : UdonConsole - Référence optionnelle à la console UdonLogger de Varneon.
- RespawnOnUnverify : bool - Si les joueurs doivent être régénérés lorsqu'ils ne sont pas vérifiés.
- IOIsSecurity : bool - Si true, accorde automatiquement le statut de sécurité au créateur de l'instance.
- SecurityNamesUrl : VRCUrl - URL externe pour obtenir les noms d'utilisateur de sécurité.
- SecurityRole : KeyPadRol - Si le joueur a ce KeyPadRol, il sera automatiquement connecté en tant que sécurité.
- SecurityNames : string[] - Liste des noms d'utilisateur qui seront automatiquement connectés en tant que sécurité.
- SecurityObjectsOn : GameObject[] - Liste d'objets qui seront activés pour les utilisateurs de sécurité.
- SecurityObjectsOff : GameObject[] - Liste d'objets qui seront désactivés pour les utilisateurs de sécurité.
- VerifiedRole : KeyPadRol - Si le joueur a ce rôle, il sera automatiquement vérifié.
- VerifiedObjectsOn : GameObject[] - Liste d'objets qui seront activés pour les utilisateurs vérifiés.
- VerifiedObjectsOff : GameObject[] - Liste d'objets qui seront désactivés pour les utilisateurs vérifiés.

### References

Vous ne devriez pas avoir besoin de changer ceux-ci à moins de savoir ce que vous faites.

BUD : BouncerUserData - PlayerObject qui stocke le niveau de sécurité de chaque joueur.
LoadingScreen : GameObject - Sera activé pendant que la liste des utilisateurs dans la gui se met à jour.
