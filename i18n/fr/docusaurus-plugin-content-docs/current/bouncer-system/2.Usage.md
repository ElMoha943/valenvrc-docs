Le système est conçu pour restreindre l'accès à des fonctionnalités spécifiques de votre monde aux nouveaux utilisateurs (invités) avant d'être vérifiés manuellement par un utilisateur de **Sécurité**. Il existe plusieurs façons de sélectionner vos utilisateurs de sécurité détaillées dans [Installation](./install).

### Vérifier un autre joueur

Une fois que vous êtes un utilisateur de Sécurité, vous pouvez utiliser la GUI pour trouver le nom d'utilisateur du joueur que vous souhaitez vérifier et cliquer sur le Toggle à côté de son nom dans la colonne "Verified". Vous verrez qu'il change en coche si c'est réussi. De la même manière, vous pouvez cliquer à nouveau sur le toggle pour les dévérifier.

![Bouncer System UI](image.png)

Vous pouvez également utiliser le prefab **Scanner** et le glisser vers votre joueur cible, puis l'utiliser (appuyer sur la gâchette en VR ou Clic Gauche sur Bureau) et vous verrez qu'il change de couleur. La couleur verte signifie vérifié avec succès, rouge signifie que vous êtes trop loin ou qu'une autre erreur s'est produite. **Vous ne pouvez pas utiliser le scanner pour dévérifier les utilisateurs**.

:::tip
Vous pouvez ajuster la distance maximale du scanner dans le script attaché à celui-ci.
:::

### Accorder le statut de sécurité à un autre joueur

Vous pouvez également utiliser la GUI pour accorder **l'Accès de Sécurité Temporaire** aux utilisateurs dans l'instance, ce statut ne dure que jusqu'à ce qu'ils quittent l'instance. Toute sécurité permanente peut ajouter/supprimer l'accès de sécurité temporaire mais vous ne pouvez pas le supprimer de ceux qui sont dans les listes permanentes.
