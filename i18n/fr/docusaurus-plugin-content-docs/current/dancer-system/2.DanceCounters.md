Les compteurs de danse apparaissent au-dessus de la tête de chaque joueur et gardent une trace du nombre de danses que ce joueur a reçues pendant l'événement. Les Dancers et Managers peuvent augmenter/diminuer les compteurs en cliquant sur les boutons +/- qui apparaissent sur les côtés. Leur visibilité peut également être basculée localement.

### Paramètres du Dance Counter

- YOffset : float - Décalage vertical du compteur au-dessus de la tête du joueur.
- MaxDances : int - Nombre maximum de danses pouvant être comptées.
- EnableColorChange : bool - Si vrai, la couleur du compteur changera en fonction du nombre de danses.
  - StartColor : Color - Couleur lorsque le compteur est à 0.
  - EndColor : Color - Couleur lorsque le compteur est à MaxDances.

### Références

- DanceCountText : TextMeshPro - Composant de texte qui affiche le nombre actuel de danses.
- CountDisplay : Image - Composant d'image d'arrière-plan du compteur, utilisé pour le changement de couleur.
- DanceCountCanvas : Canvas - Canvas qui contient l'interface utilisateur du compteur. Utilisé pour basculer la visibilité.
