---
Les listes de dancers sont utilisées pour afficher une liste synchronisée des artistes pour la soirée, vous pouvez l'utiliser pour garder une trace de l'ordre des danses, c'est particulièrement utile pour les événements de scène ouverte ou les cartes publiques car les utilisateurs peuvent s'ajouter eux-mêmes à la liste en cliquant sur un bouton. Les Managers peuvent également retirer des dancers de la liste ou ajouter manuellement des noms si nécessaire.

### Références de Dancer List

- ButtonPrefab : GameObject - Prefab utilisé pour créer chaque bouton de dancer dans la liste.
- JoinButton : GameObject - Bouton que les joueurs peuvent cliquer pour rejoindre en tant que dancers.
- LeaveButton : GameObject - Bouton que les joueurs peuvent cliquer pour quitter la liste des dancers.
- Content : Transform - Transform parent où les boutons de dancers seront instanciés.
