- Trouvez le prefab dans `Packages/valenvrc - DancerSystem/Runtime` et faites-le glisser dans votre scène.
- Ajoutez les noms d'utilisateur des managers et dancers dans les listes respectives.
- Ajustez optionnellement les paramètres dans les scripts dancersystem et dancer counter.

## Paramètres du Dancer System

- DebugMode : bool - Active les messages de log supplémentaires dans la console.
- Managers : string[] - Liste des noms d'utilisateur qui auront les permissions de manager.
- Manager Role : KeyPadRol - Si le joueur a ce KeyPadRol, il sera automatiquement connecté en tant que manager.
- Dancers : string[] - Liste des noms d'utilisateur qui auront les permissions de dancer.
- Dancer Role : KeyPadRol - Si le joueur a ce KeyPadRol, il sera automatiquement connecté en tant que dancer.

### Paramètres du Dancer Counter

- ManagersSeeCountersByDefault : bool - Si vrai, les managers verront les compteurs de dancers lorsqu'ils rejoignent l'instance.
- DancersSeeCountersByDefault : bool - Si vrai, les dancers verront les compteurs de dancers lorsqu'ils rejoignent l'instance.
- RestrictCountersToDancersAndManagers : bool - Si vrai, seuls les dancers et managers pourront activer les compteurs. Désactivez si vous prévoyez d'avoir des dancers invités ou des soirées ouvertes.

:::tip
Des paramètres supplémentaires sont situés sur le prefab [**DanceCounter**](./dance_counters), situé dans `DancerSystem/Counters/DanceCOunter`. Vous pouvez ajuster des choses comme le maximum de danses, le changement de couleur, le décalage vertical, etc.
:::

### Paramètres des Dancer Lists

- OnlyDancersCanJoin : bool - Si vrai, seuls les joueurs sur la liste des dancers ou avec le rôle de dancer pourront rejoindre en tant que dancers. Désactivez si vous prévoyez d'avoir des dancers invités ou des soirées ouvertes.
- RemoveOnExit : bool - Si vrai, les joueurs seront retirés de la liste des dancers lorsqu'ils quittent l'instance.
- DancerLists : DancerList[] - Liste des composants DancerList à mettre à jour.
