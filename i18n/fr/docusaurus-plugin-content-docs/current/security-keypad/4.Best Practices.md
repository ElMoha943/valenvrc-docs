## Hiérarchies de Rôles

Dans 90% des cas, votre monde/club/communauté a une hiérarchie de rôles, par exemple :
`Admin -> Staff -> DJ -> VIP -> Utilisateur Normal`

:::note
Vous n'avez pas besoin d'avoir un rôle pour "Utilisateur Normal", c'est un utilisateur sans rôle.
:::

Dans ces cas, les rôles supérieurs ont généralement toutes les permissions des rôles inférieurs, c'est là que la fonctionnalité de **Child Role** entre en jeu, c'est un moyen facile de fournir à un rôle toutes les permissions d'un autre sans avoir à les changer manuellement dans chaque rôle, de cette façon votre configuration de rôles est propre et facile à maintenir.

:::tip
Vous pouvez utiliser le **Keypad Checker Tool** (dans la barre supérieure : valenvrc > keypad > checker tool) pour rechercher les entrées en double et les boucles et avoir une vue claire de votre hiérarchie.
:::
