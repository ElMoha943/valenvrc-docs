## Installation

* Importez ValenCommons depuis mon [listing public VCC](https://valenvrc.com/)⚠️
* Importez SecurityKeypad.unitypackage
* Localisez le prefab SecurityKeypad dans `Packages/Valenvrc - SecurityKeypad/Runtime/SecurityKeypad` et glissez-le dans votre scène.
* Suivez les instructions de ce wiki pour le personnaliser à votre goût.
