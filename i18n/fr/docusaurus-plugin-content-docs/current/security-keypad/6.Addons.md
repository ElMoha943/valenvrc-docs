La plupart des addons sont crees pour fournir une compatibilite avec d'autres assets ou pour etendre la fonctionnalite du keypad. Ils sont optionnels et ne sont pas officiellement supportes, mais vous pouvez les essayer si vous voulez.

## VRCLinking

L'addon VRCLinking permet de lier les roles du keypad avec [VRCLinking](https://vrclinking.com/) pour accorder automatiquement un role keypad aux utilisateurs qui ont un role Discord specifique.

Pour le configurer, activez simplement l'addon et faites correspondre les noms de role entre les roles keypad et les roles VRCLinking.

:::tip
Assurez-vous d'utiliser la propriete `rolName` et non le nom du gameobject.
:::

## Role Board

Ceci cree une UI simple permettant d'afficher les noms des utilisateurs connectes a des roles specifiques.

RolGroup:

- Keypad: KeyPad - Reference au keypad pour recuperer les roles.
- Roles: KeyPadRol[] - Si le joueur possede l'un de ces roles, il sera affiche dans cette liste.
- GroupNamesText: TextMeshProUGUI - Composant texte ou les noms seront affiches.
