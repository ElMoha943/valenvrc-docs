- Trouvez le prefab dans `Packages/valenvrc - Drinking Roulette/Runtime` et glissez-le dans votre scène.
- Redimensionnez le **AutoOptInTrigger** trouvé dans le gameobject OptInOut.
  - Optionnellement, désactivez le trigger et utilisez les boutons OptIn et OptOut à la place.
- Naviguez dans ce wiki pour apprendre comment charger vos packs de prompts personnalisés et vos langues.

### Settings

- DebugMode : bool - Affiche des messages supplémentaires dans la console.
- NoRepeatMode : bool - Si true, stocke une liste de prompts qui sont déjà apparus pour éviter les doublons. Se réinitialise automatiquement si tous les prompts ont été utilisés.
- Cooldown : float - Temps en secondes à attendre entre les tours.
- WheelSets : WheelSet[] - Liste de *WheelSets* (packs de prompts) disponibles à utiliser.

### References

Vous ne devriez pas avoir besoin de toucher à ceux-ci à moins de savoir exactement ce que vous faites.

- FloatingText : TextMeshProUGUI - Texte où le prompt actuel est affiché.
- LastSpunBy : TextMeshProUGUI - Texte pour afficher le nom d'utilisateur du dernier joueur qui a fait tourner la roue.
- BottleAnimator : Animator - Animator de la bouteille.

:::note
La bouteille de la roulette tourne toujours de la même quantité et atterrit au même endroit, elle n'est pas destinée à être utilisée comme sélection de joueur, voir [variables](./wheel-sets#variables) pour une façon appropriée de sélectionner aléatoirement un joueur pour les prompts.
:::
