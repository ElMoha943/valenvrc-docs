La roulette peut charger différentes langues localement pour que chaque utilisateur voie les prompts dans sa propre langue native.
Il existe plusieurs façons de sélectionner votre langue :

### Boutons de Changement de Langue Inclus

Il y a des scripts **ChangeLangButton** inclus que vous pouvez utiliser pour changer la langue vers une clé spécifique lors de l'interaction.

### API

Vous pouvez appeler `public void _ChangeLanguage(string ll)` où li est la clé de langue vers laquelle changer.

### Verbatim

La roulette supporte également **[Verbatim](https://vowgan.gumroad.com/l/verbatim)** par vowgan, pour l'activer, importez simplement verbatim et activez le gameobject "RouletteVerbatimIntegration".
