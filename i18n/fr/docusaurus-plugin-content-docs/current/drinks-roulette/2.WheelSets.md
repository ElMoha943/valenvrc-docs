Les packs de prompts sont des paquets de questions/défis/prompts qui sont utilisés par la roulette et peuvent être sélectionnés par les utilisateurs. Les prompts sont chargés en utilisant des **URLs Externes** et supportent une URL différente par langue.

:::warning
La quantité et l'ordre des prompts doivent être les mêmes dans toutes les langues pour une synchronisation appropriée.
:::

![WheelSet Inspector](image.png)

:::info
La première langue de la liste sera utilisée si la langue de l'utilisateur local n'est pas trouvée dans le prompt !
:::

## Variables

Vous pouvez utiliser des variables à n'importe quel point dans une chaîne et elles seront remplacées.

- `{player}` - nom du joueur local.
- `{RP}` - joueur aléatoire jouant au jeu.
- `{R-X-Y}` - nombre aléatoire entre X et Y.

:::tip
Vous pouvez également utiliser les [Balises RichText](https://docs.unity3d.com/Packages/com.unity.textmeshpro@3.2/manual/RichText.html) dans vos chaînes !
:::
