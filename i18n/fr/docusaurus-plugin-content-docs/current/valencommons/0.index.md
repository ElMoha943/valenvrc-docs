Vous pouvez installer valencommons depuis mon [Listing VPM](https://valenvrc.com/), cliquez simplement sur le bouton "Add To VCC" ou copiez manuellement le lien et mettez-le dans votre Creator Companion ou ALCOM.

![Package Listing](image.png)

![Package in ALCOM](image-1.png)

Vous le trouverez dans le dossier **Packages** (pas ASSETS). Vous trouverez les scripts et prefabs dans
`Packages/Valenvrc - Common/Runtime`.
