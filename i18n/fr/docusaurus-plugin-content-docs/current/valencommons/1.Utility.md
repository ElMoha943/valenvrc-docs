### Invoke

Utilisé pour envoyer des UdonEvents lorsqu'un joueur interagit avec un objet.

- Target-MethodPairs - Liste d'UdonBehaviours avec le nom de l'événement qui sera déclenché.

### TriggerInvoke

Utilisé pour envoyer des UdonEvents lorsqu'un joueur entre dans un trigger.

- Target-MethodPairs - Liste d'UdonBehaviours avec le nom de l'événement qui sera déclenché.

### PickupInvoke

Utilisé pour envoyer des UdonEvents lorsqu'un joueur *utilise* un pickup.

- Target-MethodPairs - Liste d'UdonBehaviours avec le nom de l'événement qui sera déclenché.

### OpenGroupButton

Utilisé pour ouvrir une page de groupe spécifique lorsqu'un joueur interagit avec un objet.

- GroupIdentifier : string - identifiant du groupe que vous voulez ouvrir.

:::note
Pour obtenir l'identifiant du groupe, allez sur votre groupe et copiez la dernière partie de l'url qui commence par `grp_`.
:::

:::tip
Vous pouvez appeler `_OpenGroupPage` pour l'appeler depuis un bouton UI.
:::

### GestureInvoke

Un script utilitaire utilisé pour effectuer différentes actions lorsqu'un joueur fait un certain *geste*.

- Require Trigger Pressed : bool - Si le geste nécessite que le bouton de déclenchement du joystick soit pressé.
- Gesture Type:
  - KeyPress - Se déclenche lors de la pression d'une touche spécifique du clavier.
  - Right/Left Joystick up/down seconds - Se déclenche en maintenant le stick pendant x nombre de secondes.
  - Right/Left Joystyick up/down times - Se déclenche en effectuant x nombre de mouvements consécutifs.
- Times : int - Définit soit le temps en secondes soit le nombre de mouvements consécutifs requis pour déclencher.
- GracePeriod : float - Temps acceptable entre les mouvements consécutifs.
- Gesture Action:
  - Toggle - Alterne l'état actif d'un objet.
  - TeleportObject - Téléporte un objet vers l'emplacement cible.
  - TeleportSelf - Vous téléporte vers l'emplacement cible.
- Target Object : GameObject - L'objet qui sera téléporté/alterné.
- Target Position:
  - Front
  - Right Hand
  - Left Hand
  - Custom
- TPpoint : transform - Point cible pour l'option de position cible "Custom".
- Progress Slider : slider - Slider optionnel pour afficher la progression de l'achèvement du geste.
