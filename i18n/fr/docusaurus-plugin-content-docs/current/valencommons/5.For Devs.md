### Array Helper

Une classe statique qui contient des fonctions pour mieux gérer les tableaux.

```cs
/// <summary>
/// Ajoute un élément à un tableau, en étendant le tableau si nécessaire.
/// </summary>
/// /// <typeparam name="T">Type des éléments dans le tableau</typeparam>
/// <param name="list">Le tableau original</param>
/// <param name="item">L'élément à ajouter</param>
/// <param name="result">Message de sortie indiquant le résultat de l'opération</param>
/// <returns>Un nouveau tableau avec l'élément ajouté, ou le tableau original si l'élément existe déjà</returns>
/// <remarks>
/// Si l'élément existe déjà dans le tableau, il ne sera pas ajouté à nouveau.
/// </remarks>
public static T[] AddToList<T>(T[] list, T item, out string result)
```

```cs
/// <summary>
/// Vérifie si un élément existe dans un tableau.
/// </summary>
/// <param name="array"></param>
/// <param name="item"></param>
/// <typeparam name="T"></typeparam>
/// <returns></returns>
public static bool Contains<T>(T[] array, T item)
```

```cs
/// <summary>
/// Supprime un élément d'un tableau, en réduisant optionnellement le tableau.
/// </summary>
/// <typeparam name="T">Type des éléments dans le tableau</typeparam>
/// <param name="list">Le tableau original</param>
/// <param name="item">L'élément à supprimer</param>
/// <param name="result">Message de sortie indiquant le résultat de l'opération</param>
/// <param name="shrink">Si true, le tableau sera réduit après suppression de l'élément</param>
/// <returns>Un nouveau tableau avec l'élément supprimé, ou le tableau original si l'élément n'a pas été trouvé</returns>
public static T[] RemoveFromList<T>(T[] list, T item, out string result, bool shrink = false)
```
