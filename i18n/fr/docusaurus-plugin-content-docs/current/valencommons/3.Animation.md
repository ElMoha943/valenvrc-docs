Une sélection de scripts pour contrôler les paramètres d'animation.

### Animator Toggle

Bascule un paramètre booléen sur un composant Animator. Peut être utilisé en **Interagissant** avec lui si un Collider est attaché ou en appelant `_Toggle()` depuis un composant UI ou un autre script.

- Anim : Animator - Le composant Animator à contrôler.
- ParameterName : string - Le nom du paramètre booléen à basculer.

### Synced Animator Toggle

Identique à **Animator Toggle**, mais synchronisé avec tous les joueurs.

- Anim : Animator - Le composant Animator à contrôler.
- ParameterName : string - Le nom du paramètre booléen à basculer.

### Trigger Animator Toggle

Bascule un paramètre booléen sur un composant Animator lorsqu'un joueur entre dans un collider trigger. Peut être utilisé en attachant un Collider avec "Is Trigger" activé.

- Anim : Animator - Le composant Animator à contrôler.
- ParameterName : string - Le nom du paramètre booléen à basculer.
- WorkForAllPlayers : bool - Si activé, n'importe quel joueur entrant dans le trigger basculera le paramètre pour tous les joueurs. Si faux, seul le joueur local sera détecté.

### Animator Activator

Bascule un paramètre booléen basé sur l'état actif du GameObject auquel il est attaché.

- Anim : Animator - Le composant Animator à contrôler.
- ParameterName : string - Le nom du paramètre booléen à basculer.
