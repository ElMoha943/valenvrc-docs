Une sélection de scripts pour basculer diverses choses activées et désactivées.

### Trigger Toggle

Bascule l'état actif d'un GameObject lorsqu'un joueur entre dans un collider trigger. Peut être utilisé en attachant un Collider avec "Is Trigger" activé.

- ToggleableObjects : GameObject[] - Les GameObjects à basculer.

:::note
Fonctionne uniquement pour le joueur local.
:::
