Scripts pour contrôler les pickups.

### Local Object Respawn

Fait réapparaître un objet local, le renvoyant à sa position d'origine. Peut être utilisé en **Interagissant** avec lui si un Collider est attaché ou en appelant `_Respawn()` depuis un composant UI ou un autre script.

- objectToRespawn : GameObject - Le GameObject à faire réapparaître.
- respawnPoint : Transform - (Optionnel) Le Transform où l'objet réapparaîtra. Si aucun n'est assigné, il réapparaîtra à sa position d'origine.

### Respawn Pickups

Fait réapparaître un ou plusieurs objets synchronisés. Peut être utilisé en **Interagissant** avec lui si un Collider est attaché ou en appelant `_RespawnPickups()` depuis un composant UI ou un autre script.

- Objects : VRCObjectSync[] - Liste des composants VRCObjectSync à faire réapparaître.
- RespawnHeldItems : bool - Si vrai, fera également réapparaître les objets actuellement tenus par les joueurs.

### Pickup Invoke

Utilisé pour envoyer des UdonEvents lorsqu'un joueur *utilise* le pickup attaché.

- Target-MethodPairs - Liste d'UdonBehaviours avec le nom de l'événement qui sera déclenché.

### Pickup Reset Zone

Lâche et fait réapparaître tous les pickups synchronisés tenus lorsqu'un joueur entre dans le collider trigger. Peut être utilisé en attachant un Collider avec "Is Trigger" activé.

- Objects : VRCObjectSync[]  - (Optionnel) Liste des composants VRCObjectSync à faire réapparaître. Si aucun n'est assigné, il fera réapparaître tous les pickups synchronisés tenus par le joueur entrant dans le trigger.
