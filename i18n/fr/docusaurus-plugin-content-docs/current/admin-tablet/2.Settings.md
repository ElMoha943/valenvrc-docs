## Security

Cette partie est utilisée pour se connecter avec des systèmes externes pour les vérifications de sécurité.

* **PlayerTags** : utilise le système de [PlayerTags](https://creators.vrchat.com/worlds/udon/players/getting-players/#player-tag-system) intégré à vrchat.
  * **TagName** : nom du tag.
  * **SplitChar** : caractère pour séparer les tags.
* **SecurityKeypad** : utilise les noms de rôles du [Security Keypad](https://store.valenvrc.com/i/SecurityKeypad) pour les permissions.
  * Référence au Security Keypad.
* **UdonBridge** : [En Développement]
* **VRCLinking** : [En Développement]

:::info
La tablette elle-même n'inclut pas de système de gestion de rôles, vous avez besoin d'un autre système pour qu'elle fonctionne !
:::

## References

Ce sont des références utilisées par la tablette, principalement des composants UI, vous ne devriez pas avoir besoin de les toucher à moins de savoir exactement ce que vous faites.

* Handle - La poignée de la tablette, c'est là que se trouve le composant pickup et elle est affectée par le redimensionnement.
* POV Camera - Gameobject FollowerCamera, sera placé à la tête du joueur cible pendant qu'il est dans l'onglet profil.
* Profile - Onglet ModerationView. Onglet spécial qui s'ouvre quand vous cliquez sur le nom d'un joueur dans l'onglet de modération ; il affiche les informations du joueur et les actions de modération.
* HiddenParent - Où seront placés les onglets inactifs.
* Active Parent - Où sera placé l'onglet actif.
* Content - Le contenu du viewport rempli avec des boutons de joueurs dans l'onglet de modération.
* Title_Username - TextMeshProUGUI dans l'onglet profil qui affiche le nom du joueur ciblé.
* Title_OnlineUsers - TextMeshProUGUI dans l'onglet de modération qui affiche le nombre de joueurs.
* DummyButton - Prefab utilisé pour instancier les boutons de joueurs dans l'onglet de modération.
* EmptyTabPrefab - Prefab utilisé pour instancier de nouveaux onglets depuis les paramètres.
* SelectorContent - Endroit où les boutons d'onglet sont placés.
* SelectorButtonPrefab - Prefab utilisé pour instancier les boutons d'onglet dans le sélecteur.
* ClickSound - Son joué lors d'un clic sur un bouton.
* TabChangeSound - Son joué lors du changement d'onglet.
