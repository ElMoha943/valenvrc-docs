* **Importez ValenCommons depuis mon [listing public VCC](https://valenvrc.com/)⚠️**
* Importez AdminTablet.unitypackage
* Localisez le prefab AdminTablet dans `Packages/Valenvrc - AdminTablet/Runtime/AdminTablet` et glissez-le dans votre scène.
* Suivez les instructions de ce wiki pour le personnaliser à votre goût.

:::danger[Considérations Importantes :]

* NE désactivez JAMAIS le gameobject de la tablette ou ses modules, tous sont nécessaires pour que la tablette fonctionne correctement.
* Gardez tous les modules comme enfants du script principal Tablet ou ils ne pourront pas trouver la référence à celui-ci pour les notifications et les vérifications de permissions.

:::
