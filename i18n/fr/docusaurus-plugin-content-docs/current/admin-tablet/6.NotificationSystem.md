Le système de notifications est utilisé pour enregistrer et afficher les actions à l'utilisateur. Il est important de le laisser activé pour se conformer aux [Directives des Outils de Modération](https://hello.vrchat.com/creator-guidelines).

### Settings

- ShowNotifications : bool - Affiche les notifications à l'écran.
- ShowLogs : bool - Affiche les logs dans la console.
- Time : Float - Temps en secondes que les notifications à l'écran restent.
- MaxNotifications : int - Quantité maximale simultanée de notifications à l'écran.
- NotificationIcon : Sprite - Icône par défaut pour les notifications.
- NotificationSound : AudioClip - Son par défaut pour les notifications.
- Volume : Float - Volume des sons de notifications.
- UdonConsole : UdonConsole - Référence optionnelle pour VUdonLogger Console.

### Notifications

Vous pouvez ajuster certaines choses dans chaque type de notification, y compris :

- L'activer/Désactiver complètement
- Icône
- Son
- Traductions, dans lesquelles le {0} signifie des variables.

### References

Références internes utilisées par le système, *vous ne devriez pas avoir besoin de les toucher*

- Container : transform - où apparaîtront les nouvelles notifications.
- DummyNotification : GameObject - prefab à partir duquel de nouvelles notifications sont instanciées.
