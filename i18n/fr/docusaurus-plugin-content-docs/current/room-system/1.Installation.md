* **Importez ValenCommons depuis ma [liste VCC publique](https://valenvrc.com/)⚠️**
* Importez RoomSystem.unitypackage
* Localisez le prefab RoomSystem dans `Packages/Valenvrc - RoomSystem/Runtime/` et glissez-le dans votre scène.
* Suivez les instructions de ce wiki pour le personnaliser à votre goût.

## Configuration d'une Salle

Le prefab RoomSystem par défaut est livré avec un exemple de salle déjà configuré, vous pouvez l'utiliser comme référence pour créer vos propres salles. Pour créer une nouvelle salle :

1. Dupliquez le modèle `Room1` trouvé dans le GameObject `Rooms`.
![alt text](/img/docs/room-system/room-duplicate.png)
2. Ajoutez la nouvelle salle au tableau `Rooms` dans le composant `RoomSystem`.
3. Redimensionnez le collider de la salle pour qu'il couvre toute la zone de votre salle.
![alt text](/img/docs/room-system/room-collider.png)
