Installation

info

These docs were last updated for ValenCommons 2.10.0.

ValenCommons is a free dependency used by other Valen assets.

  1. Open the Valen VPM listing.
  2. Press Add To VCC, or copy the listing URL into Creator Companion or ALCOM.
  3. Add ValenCommons to the Unity project.

The package is installed under Packages/com.valenvrc.commons. Runtime scripts and prefabs are in its Runtime folder.

tip

Install or update ValenCommons before importing a paid Valen asset that depends on it.
