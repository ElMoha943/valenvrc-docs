Installation

Vous pouvez installer valencommons depuis mon Listing VPM, cliquez simplement sur le bouton "Add To VCC" ou copiez manuellement le lien et mettez-le dans votre Creator Companion ou ALCOM.

Vous le trouverez dans le dossier Packages (pas ASSETS). Vous trouverez les scripts et prefabs dans Packages/Valenvrc - Common/Runtime.
