slug: animation
title: Animation
description: Control Animator parameters from interactions and triggers.
---

:::info
These docs were last updated for ValenCommons 2.10.0.
:::

| Component | Behavior |
| --- | --- |
| Animator Toggle | Toggles a local Animator boolean on interaction or `_Toggle()`. |
| Synced Animator Toggle | Synchronizes the boolean state for all users. |
| Trigger Animator Toggle | Toggles a boolean when a player enters the attached trigger. **Work For All Players** chooses between any player and the local player only. |
| Animator Activator | Sets a boolean from the active state of the component's GameObject. |
| Distance Animator Trigger | Drives a float from the local user's distance to **Target Transform**. |

For the distance component, the parameter is `1` at **Max Distance** or closer and `0` at **Min Distance** or farther, with a value between them.

All components require the target Animator and exact parameter name.
