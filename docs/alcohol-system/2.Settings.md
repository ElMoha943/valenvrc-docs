## General

| Setting | Purpose |
| --- | --- |
| Debug Mode | Prints additional diagnostic messages. |
| Sober On Respawn | Resets the local alcohol level after respawn. |
| Alcohol Decay | Alcohol level removed per second. |
| Drink Sound | Default sound for consumed drinks. |
| Enable Drunk Effect | Enables the local screen effect. |
| Drunk PPV | Optional post-process volume controlled by alcohol level. |
| Visualizer / Shader Parameter | Optional visualizer and parameter driven by alcohol level. |

## Puke

When enabled, each drink consumed above **Puke Threshold** can trigger puking according to **Puke Chance**. **Puke Amount** lowers the alcohol level, and **Puke Cooldown** limits repeats. The sound and particles are optional feedback.

## Blackout

When enabled, each drink consumed above **Blackout Threshold** can trigger a blackout according to **Blackout Chance**. A blackout selects a random configured destination and uses the optional Animator trigger before teleporting the local player.
