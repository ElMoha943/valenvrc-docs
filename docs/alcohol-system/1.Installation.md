## Requirements

Install [ValenCommons](../valencommons/install) from the Valen VPM listing first.

## Install

1. Import the provided Alcohol System `.unitypackage` file.
2. Locate `Packages/com.valenvrc.alcohol_system/Runtime/Alcohol System.prefab`.
3. Drag the prefab into the scene.
4. Configure the main [Alcohol System settings](./settings).

The full prefab includes the runtime system and drinks machine. Individual prefabs are also available in `Runtime/Prefabs`.
