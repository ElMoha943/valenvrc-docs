The drinks machine is an additional component that can be added to the alcohol system to provide drink dispensing functionality.

## Steps to Use

1. Select a glass type from the available glass meshes.
2. Customize the drink's color and alcohol level using the provided UI sliders.
3. (NOT IMPLEMENTED) Optionally, enable additional drink features such as ice, cherry, mint, or smoke
4. Click the **Serve Drink** and it will appear on the pool of objects.

If you dont have more glasses you can use the **Reset All Drinks** button to return all drinks to the pool.

:::note
You can also use the included **Trash Bin** prefab to return drinks to the pool.
:::

---

## Drink Parts

* GlassMeshes: Mesh[] - The available glasses types that can be used for drinks.

## References

These are references used by the drinks machine, you shouldn't need to touch these unless you know exactly what you are doing.

* GlassPool : VRCObjectPool - Contains the drinkable glasses used by the system.
* AlcoholSystem : AlcoholSystem - Reference to the main alcohol system.
* DummyGlass : GameObject - Local glass that is used for previewing drinks in the machine UI.

### UI References

These are references to the UI components used by the drinks machine.

* RedChannel : Slider - Red color channel for customizing drink color.
* GreenChannel : Slider - Green color channel for customizing drink color.
* BlueChannel : Slider - Blue color channel for customizing drink color.
* AlphaChannel : Slider - Alpha channel for customizing drink color.
* AlcoholLevel : Slider - Alcohol level for the drink.

* RedLabel : TextMeshProUGUI - Text label for the red color channel.
* GreenLabel : TextMeshProUGUI - Text label for the green color channel.
* BlueLabel : TextMeshProUGUI - Text label for the blue color channel.
* AlphaLabel : TextMeshProUGUI - Text label for the alpha channel.
* AlcoholLabel : TextMeshProUGUI - Text label for the alcohol level.

:::note
Options below are not yet implemented.
:::

* IcedToggle : Toggle - Toggle for adding ice to the drink.
* CherryToggle : Toggle - Toggle for adding a cherry to the drink.
* MintToggle : Toggle - Toggle for adding mint to the drink.
* SmokeToggle : Toggle - Toggle for adding smoke effect to the drink.
