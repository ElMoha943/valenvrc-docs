:::info
These docs were last updated for Alcohol System 2.0.0-Beta15.
:::

The Drinks Machine creates synchronized glasses from its object pool. Users can choose:

- a glass mesh;
- drink color and emission intensity;
- alcohol level;
- whether the drink includes ice.

Pressing create takes an available glass from **Glass Pool** and applies those values. The included trash bin returns a glass to the pool, and `_ResetGlasses()` returns all active glasses.

The glass meshes, pool, Alcohol System, preview glass, sliders, labels, and toggles are configured on the supplied prefab. Review them only when changing the machine UI or expanding its pool.

:::note
The Cherry, Mint, and Smoke controls are present in the current UI but are not applied to spawned glasses in 2.0.0-Beta15.
:::
