Drinkable objects are the core components of the alcohol system. These objects represent the drinks that players can consume to increase their alcohol level.

You can attach the `DrinkableObject` script to any object you want to make drinkable. Keep in mind that this requires both a **VRCObjectSync** and **VRCPickup** component to function properly.

## Settings

* AlcoholLevel: float (0-1) - The amount of alcohol this drink will add to the drinker upon consumption.
* DrinkSoundOverride: AudioClip - Sound played when the drink is consumed, if none uses the alcohol system default.
* AlcoholSystem: AlcoholSystem - Reference to the main alcohol system. If left empty, it will try to find one in the scene at runtime.
