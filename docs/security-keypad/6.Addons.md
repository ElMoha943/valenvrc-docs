Addons are optional and only compile when their matching dependency is present.

## VRCLinking

Assign the Keypad, then match VRCLinking role names to the exact Security Keypad role names. **Stop At First Match** grants only the first matching role.

## Role Board

Displays players who hold any configured role.

| Setting | Purpose |
| --- | --- |
| Keypad | Role source. |
| Roles | Roles included in this board group. |
| Include Implicit Roles | Includes inherited child roles. |
| Group Names Text | Text component that displays player names. |

## ProTV

`ProTVKeypadAuth` maps **Super User Roles** and **Authorized User Roles** to ProTV authorization levels.

## VideoTXL

`VideoTXLAccessControl` allows users with any configured **Roles With Access**. **Pass To Next Handler** continues the VideoTXL access chain when no role matches; otherwise access is denied.
