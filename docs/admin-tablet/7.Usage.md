## Open and navigate the tablet

1. Pick up the tablet.
2. Use the selector at the bottom to open a tab.
3. Use **Respawn Tablet** gesture or button if the tablet is lost or moved out of reach.

If a tab refuses to open, you may not have the required permissions. See [Settings](./settings#security) for permission modes.

## Moderate a player

1. Open the **Moderation** (playerlist) tab.
2. Select a player from **Online Users**. The list is sorted alphabetically.
3. Use the actions in the selected player's profile.
4. Press the close button to clear the target and return to **Moderation**.

The profile camera follows the selected player's head while their profile is open.

## Understand action scope

Some actions are local (only affect you), some require a **Target** user (like moderation actions) and others affect the whole instance (like an announcement or synced toggle).

| Scope | Modules |
| --- | --- |
| Local user | Local Toggle, Local Chain Toggle, Local TP, and Goto. |
| Selected player | Bring, Remote TP, Warn, Ban, Freeze, and Mute / Deafen. |
| Instance or shared objects | Announcement, Bring All, Global TP, Global Chain Toggle, Synced Toggle, and Object Respawn. |

:::info Targeted Modules
The modules that require a target **need** to be placed inside the moderation view tab. Otherwise they will not work correctly.
:::

## Read feedback

Successful actions, permission failures, and invalid targets use the configured [Notification System](./notification-system) to write logs when and show in-screen messages. You can use those to debug and confirm that the tablet is working as expected.
