## Requirements

- Unity `2022.3.22f1`
- VRChat Worlds SDK `3.10.5` or newer
- ValenCommons `2.10.0` or newer

### Optional Dependencies

- Security Keypad `7.4.0` or newer
- VUdon Logger `0.3` or newer

:::warning
Install [ValenCommons](../valencommons/install) from the Valen VPM listing **before** importing Admin Tablet.
:::

## Add Admin Tablet to a scene

1. Import the provided Admin Tablet `.unitypackage` into your world project.
2. In Unity, locate `Packages/com.valenvrc.admin_tablet/Runtime/AdminTablet.prefab`.
3. Drag `AdminTablet.prefab` into the scene.
4. Select the tablet and choose a [security mode](./settings#security).
5. Tweak [tabs](./tabs) and [modules](./modules) as needed.
6. Test the tablet inside VRChat to ensure it works as expected.

:::warning Required hierarchy
Keep the tablet, its notification system, tabs, and modules enabled. Modules must remain below the tablet in the hierarchy so the tablet can find and initialize them.
:::

Continue with [Settings](./settings) to configure access, then [Usage](./usage) to learn the in-world workflow.
