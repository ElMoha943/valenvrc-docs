## Requirements:
* Unity version 2022+. Vrchat currently uses 2022.3.22f1
* A project created using Creator Companion or ALCOM, with the latest SDK Base & Worlds.
* My personal library of public scripts “Valen Commons”  that can be found [here](https://valenvrc.com/).
## Installation:
* **Import ValenCommons from my [public VCC listing](https://valenvrc.com/)⚠️**
* Import AdminTablet.unitypackage
* Locate the AdminTablet prefab inside `Packages/Valenvrc - AdminTablet/Runtime/AdminTablet` and drag it to your scene.
* Follow this wiki instructions to customize it to your liking.
## Updating from an old version
* **Make a backup of your config!**
* If you are upgrading from a really old version, double check if you have a folder called "ValeStuff" on the Assets folder. If you do, remove the "Public Scripts" and "AdminTablet" folders from it.
* It is always adviced to perform a **clean install**, which means removing the package files before installing the new version.
* Make sure to also perform a clean install of valencommons and any other dependencies.

:::danger[Important Considerations:]
* NEVER turn off the tablet gameobject or their modules, they are all needed for the tablet to work properly. 
* Keep all modules as childs of the main Tablet script or they won't be able to find the reference to it for notifications and permission checks.
:::
