description: These track the list of dancers performing tonight.
---
The dancer lists are used to show a synced list of performers for the night, you can use it to keep track of the dance order, its specially useful for open stage events or public maps since users can add themselfs to the list by clicking a button. Managers cal also remove dancers from the list or manually add names if needed.

### Dancer List References

- ButtonPrefab : GameObject - Prefab used to create each dancer button in the list.
- JoinButton : GameObject - Button that players can click to join as dancers.
- LeaveButton : GameObject - Button that players can click to leave the dancers list.
- Content : Transform - Parent transform where the dancer buttons will be instantiated.
