---
slug: dancer-lists
title: Dancer Lists
description: Create queues that dancers can join and managers can edit.
---

:::info
These docs were last updated for Dancer System 1.6.0.
:::

Use the included `DancerList` prefab for each queue. Assign every list to the main Dancer System's **Dancer Lists** array.

Each list contains:

- the player-button prefab used for entries;
- join and leave controls;
- the content transform where entries are created.

Users join or leave their own entry from the list controls. Configured managers can remove other players. **Only Dancers Can Join** and **Remove On Exit** are global settings on the main system.
