## Requirements

Install [ValenCommons](../valencommons/install) first. Security Keypad and VUdon Logger integrations are optional.

## Install

1. Import the provided Dancer System `.unitypackage` file.
2. Locate `Packages/com.valenvrc.dancer_system/Runtime/DancerSystem.prefab`.
3. Drag the prefab into the scene.
4. Configure manager and dancer assignment on the main component.

| Setting | Purpose |
| --- | --- |
| Managers / Manager List URL / Manager Role | Exact display-name lists and optional Security Keypad role that can remove dancers. |
| Dancers / Dancer List URL / Dancer Role | Exact display-name lists and optional role treated as dancers. |
| Managers Count As Dancers | Lets managers satisfy dancer-only joining rules. |
| Only Dancers Can Join | Restricts joining to configured dancers and eligible managers. |
| Remove On Exit | Removes a player from a dance list when they leave its area. |
| Dancer Lists | Lists controlled by this system. |

Remote lists use one case-sensitive display name per line.
