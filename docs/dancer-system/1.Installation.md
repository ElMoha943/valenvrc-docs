- Find the prefab on `Packages/valenvrc - DancerSystem/Runtime` and drag it to your scene.
- Add manager and dancer usernames on the respective lists.
- Optionally tweak settings on both dancersystem and dancer counter scripts.

## Dancer System Settings

- DebugMode : bool - Enables additional log messages on the console.
- Managers : string[] - List of usernames that will have manager permissions.
- Manager Role : KeyPadRol - If the player has this KeyPadRol it will be automatically logged in as manager.
- Dancers : string[] - List of usernames that will have dancer permissions.
- Dancer Role : KeyPadRol - If the player has this KeyPadRol it will be automatically logged in as dancer.

### Dancer Counter Settings

- ManagersSeeCountersByDefault : bool - If true, managers will see the dancer counters when they join the instance.
- DancersSeeCountersByDefault : bool - If true, dancers will see the dancer counters when they join the instance.
- RestrictCountersToDancersAndManagers : bool - If true, only dancers and managers will be able to toggle on the counters. Leave off if you plan to have guest dancers or open nights.

:::tip
Extra settings are located on the [**DanceCounter**](./dance_counters) prefab, located on `DancerSystem/Counters/DanceCOunter`. You can tweak things like max dances, color change, vertical offset, etc.
:::

### Dancer Lists Settings

- OnlyDancersCanJoin : bool - If true, only players on the dancers list or with the dancer role will be able to join as dancers. Leave off if you plan to have guest dancers or open nights.
- RemoveOnExit : bool - If true, players will be removed from the dancers list when they exit the instance.
- DancerLists : DancerList[] - List of DancerList components to update.
