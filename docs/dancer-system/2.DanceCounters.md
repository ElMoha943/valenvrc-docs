The dance counters appear above each players head and keep track of the amount of dances that player has received during the event. Dancers and Managers can increase/decrease the counters by clicking in the +/- buttons that appear in the sides. Their visibility can also be toggled locally.

### Dance Counter Settings

- YOffset : float - Vertical offset of the counter above the players head.
- MaxDances : int - Maximum amount of dances that can be counted.
- EnableColorChange : bool - If true, the counter color will change based on the amount of dances.
  - StartColor : Color - Color when the counter is at 0.
  - EndColor : Color - Color when the counter is at MaxDances.

### References

- DanceCountText : TextMeshPro - Text component that shows the current dance count.
- CountDisplay : Image - Image component background of the counter, this is used for color change.
- DanceCountCanvas : Canvas - Canvas that holds the counter UI. Used to toggle visibility.
