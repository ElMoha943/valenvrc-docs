:::info
These docs were last updated for Dancer System 1.6.0.
:::

Add or duplicate the included `DanceCounter` prefab, then assign it to the intended dancer list or controls.

Counter presentation is configured on the main Dancer System:

| Setting | Purpose |
| --- | --- |
| Offset | Position relative to the tracked dancer. |
| Enable Color Change | Blends from **Start Color** to **End Color** as the count approaches the maximum. |
| Disable At Max Count | Stops the add action at **Max Dance Count**. |
| Manager / Dancer Default Visibility | Chooses who sees counters by default. |
| Restrict Counter Visibility | Limits visibility to managers and dancers. |
| Hide Staff Counters | Hides counters attached to managers. |
| No Dances / Max Dances Text | Messages shown at the counter limits. |

The public counter actions are `_AddDance()`, `_RemoveDance()`, and `_ResetDances()`.
