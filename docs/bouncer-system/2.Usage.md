The system is designed to restrict access to specific features of your world to new users (guest) before being manually verified by a **Security** user. There are multiple ways to select your security users detailed on [Installation](./installation).

### Verifying another player

Once you are a Security user, you can use the GUI to find the username of the player you want to verify and click on the Toggle nexto their name in the "Verified" column. You will see it change to a checkmark if it succeeds. In the same way, you can click the toggle again to unverify them.

![Bouncer System UI](image.png)

You can also use the **Scanner** prefab and drag it to your target player then use it (press trigger on VR or Left Click on Desktop) and you will see it change color. Green color means successfully verified, red means you are too far or some other error happend. **You cannot use the scanner to unverify users**.

:::tip
You can tweak the max distance of the scanner on the script attached to it.
:::

### Granting security status to other player

You can also use the GUI to grant **Temporal Security Access** to users in the instance, this status only last until they leave the instance. Any permanent security can add/remove temporal security access but you cannot remove it from those that are on permanent lists.
