## Requirements

Install [ValenCommons](../valencommons/install) first.

## Install

1. Import the provided Drinking Roulette `.unitypackage` file.
2. Locate `Packages/com.valenvrc.drinking_roulette/Runtime/DrinkingRoulette.prefab`.
3. Drag the prefab into the scene.
4. Resize **AutoOptInTrigger** to cover the play area, or disable it and use the included opt-in and opt-out buttons.
5. Configure the available [Wheel Sets](./wheel-sets).

| Setting | Purpose |
| --- | --- |
| Debug Mode | Prints additional diagnostic messages. |
| No Repeat Mode | Removes used prompts until every prompt has appeared, then resets the pool. |
| Cooldown | Seconds the same local user must wait between spins. |
| Wheel Sets | Prompt packs available from the selector. |

:::note
The bottle animation is visual. Use prompt variables when a result needs a synchronized player or number selection.
:::
