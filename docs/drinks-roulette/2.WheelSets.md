:::info

:::

A Wheel Set pairs each **Language Key** with a direct text-file URL. Put one prompt on each line.

![WheelSet Inspector](/img/docs/drinks-roulette/wheelset-inspector.png)

:::warning
Every language in a Wheel Set must contain the same number of prompts in the same order. The synchronized result is an index, while each user displays the matching line in their selected language.
:::

If the selected language is missing, the first entry is used.

## Variables

| Variable | Replacement |
| --- | --- |
| `{player}` | Local viewer's display name. |
| `{spinner}` | Display name of the user who spun. |
| `{RP}` | Random opted-in player other than the spinner. |
| `{N5}` | The number `5` multiplied by the active multiplier. Any whole number can be used. |
| `{R-1-6}` | Inclusive random number from `1` to `6`, multiplied by the active multiplier. |

TextMesh Pro rich-text tags are supported in prompt lines.
