slug: languages
title: Languages
description: Change the prompt language locally.
---

:::info
These docs were last updated for Drinking Roulette 1.2.2.
:::

Each user loads prompts in their own selected language while sharing the same synchronized prompt index.

- Use the included `ChangeLangButton` and enter a matching Wheel Set language key.
- From UdonSharp, call `_ChangeLanguage(string ll)` with that key.
- To load a user-provided pack, call `_LoadCustomSet(VRCUrl url)` or use the included custom URL input.

If [Verbatim](https://vowgan.gumroad.com/l/verbatim) is installed, enable the included `RouletteVerbatimIntegration` to pass language changes to the roulette.
