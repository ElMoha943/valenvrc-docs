## Description:
Add floating images or text that follow players!
## Requirements:
* Unity version 2022+. Vrchat currently uses 2022.3.22f1
* A project created using Creator Companion or ALCOM with the latest SDK (currently 3.8.2)
* My personal library of public scripts “Valen Commons”  that can be found [here](https://valenvrc.com/).
## Installation:
* Import ValenCommons from my [public VCC listing](https://valenvrc.com/)⚠️
* Import FloatingTags.unitypackage
* Locate the FloatingTags prefab inside `Packages/Valenvrc - FloatingTags/Runtime/FloatingTags` and drag it to your scene.
* Follow this wiki instructions to customize it to your liking.
